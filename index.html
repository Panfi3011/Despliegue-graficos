¿Qué es HTML Canvas?

La etiqueta canvas de HTML permite crear un área de dibujo dentro de una página web. Mediante JavaScript se pueden dibujar líneas, figuras geométricas, textos e imágenes.

Contexto de renderizado 2D

El método getContext("2d") obtiene el contexto que permite realizar operaciones de dibujo en dos dimensiones. Con él podemos cambiar colores, dibujar rectángulos, crear círculos y trazar líneas. 

const canvas = document.getElementById("miCanvas");
const ctx = canvas.getContext("2d");

ctx.fillStyle = "red";
ctx.fillRect(20, 20, 100, 60);

En este ejemplo, fillStyle establece el color rojo y fillRect dibuja un rectángulo. Los valores indican la posición horizontal, la posición vertical, el ancho y la altura.

Características de Canvas

  • Permite crear dibujos mediante instrucciones JavaScript.
  • Trabaja con coordenadas horizontales (X) y verticales (Y).
  • Puede utilizarse para animaciones y juegos.
  • Los dibujos se actualizan mediante nuevas instrucciones de código.

Fundamentos de la librería p5.js

p5.js es una biblioteca de JavaScript que facilita la creación de dibujos, animaciones e interacciones. Está diseñada para trabajar de forma sencilla con elementos visuales y programación creativa.

Funciones principales

  • setup(): se ejecuta al iniciar el programa y permite preparar el área de dibujo.
  • draw(): se ejecuta repetidamente para dibujar o actualizar la animación.
  • createCanvas(): crea el área de dibujo.
  • background(): establece el fondo.
  • ellipse(): dibuja una elipse o un círculo.
  • rect(): dibuja un rectángulo.
  • fill(): establece el color de relleno.

Ejemplo de código p5.js

function setup() {
    createCanvas(300, 200);
}

function draw() {
    background(230, 240, 255);
    fill(220, 60, 60);
    ellipse(150, 100, 80, 80);
}

Este programa crea un área de dibujo, establece un fondo azul claro y dibuja un círculo rojo. La función draw permite actualizar el dibujo continuamente, lo cual es útil para crear animaciones.
