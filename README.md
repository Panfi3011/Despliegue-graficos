# Portafolio de Dibujo Digital

## Descripción del proyecto

Este proyecto consiste en el desarrollo de un sitio web dedicado a presentar una colección de dibujos digitales adaptados de las prácticas realizadas en Khan Academy. El portafolio utiliza HTML, CSS y JavaScript para organizar y mostrar los dibujos mediante herramientas de programación web.

El objetivo es comprender cómo se pueden adaptar los programas de dibujo a un entorno web, utilizando el elemento HTML Canvas y la librería p5.js para representar figuras geométricas, líneas, colores y otros elementos gráficos.

## Objetivo

Desarrollar un sitio web funcional que permita visualizar diferentes dibujos digitales y consultar información teórica sobre HTML Canvas, los contextos de renderizado 2D y los fundamentos de la librería p5.js.

## Proyectos incluidos

El portafolio contiene los siguientes cinco dibujos adaptados de Khan Academy:

1. **Rana:** dibujo de un personaje utilizando elipses, rellenos y figuras geométricas.
2. **Dientes de conejo:** representación de un conejo mediante elipses, líneas y rectángulos.
3. **¿Qué hay de cena?:** dibujo de una pizza sobre un plato, utilizando figuras geométricas y colores.
4. **Día nevado soleado:** paisaje con cielo, suelo, sol y muñeco de nieve.
5. **Muñeco de nieve:** representación de un muñeco mediante figuras geométricas y líneas.

## Estructura del sitio web

El sitio se organiza en las siguientes secciones:

- **Inicio:** presentación del portafolio.
- **Proyectos:** galería con los cinco dibujos digitales.
- **HTML Canvas:** explicación de la etiqueta canvas y del contexto de renderizado 2D.
- **Librería p5.js:** descripción de sus funciones principales y su aplicación en dibujos y animaciones.
- **Acerca del proyecto:** información general sobre la finalidad del trabajo.
- **Arbol DOM**

## Conceptos teóricos

### HTML Canvas y renderizado 2D

La etiqueta `<canvas>` permite definir un área dentro de una página web en la que se pueden generar gráficos mediante JavaScript. El método `getContext("2d")` proporciona las herramientas necesarias para dibujar líneas, rectángulos, círculos, elipses y otras figuras en dos dimensiones.

### Librería p5.js

p5.js es una librería de JavaScript orientada a la programación creativa. Facilita la creación de dibujos, animaciones e interacciones visuales mediante funciones como `setup()`, `draw()`, `createCanvas()`, `background()`, `ellipse()`, `rect()` y `fill()`.
